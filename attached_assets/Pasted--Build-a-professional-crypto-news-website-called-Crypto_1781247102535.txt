
Build a professional crypto news website called "CryptoNewsTrend" in Next.js 15 (App Router) with Tailwind CSS v4. It should be a pixel-perfect clone of cryptonewstrend.com with full SEO, dark/light mode, SSR/SSG, and sitemap support.

## TECH STACK
- Next.js 15 (App Router)
- Tailwind CSS v4
- TypeScript
- next-themes (dark/light mode)
- next-sitemap (sitemap + robots.txt)
- next/font (Google Fonts: Space Grotesk for headings, Inter for body)
- Dummy JSON data (no real API needed, use mock data)

## SEO (CRITICAL)

### Every page must have:
```tsx
// app/layout.tsx
export const metadata: Metadata = {
  metadataBase: new URL('https://cryptonewstrend.com'),
  title: { default: 'CryptoNewsTrend', template: '%s | CryptoNewsTrend' },
  description: 'Latest crypto news, whale tracking, ICO launchpad...',
  keywords: ['crypto news', 'bitcoin', 'ethereum', 'blockchain', 'whale tracker'],
  openGraph: { type: 'website', locale: 'en_US', siteName: 'CryptoNewsTrend' },
  twitter: { card: 'summary_large_image', site: '@cryptonewstrend' },
  robots: { index: true, follow: true, googleBot: { index: true, follow: true } },
  alternates: { canonical: '/' }
}
```

### Per-page dynamic metadata using generateMetadata()
### JSON-LD structured data on homepage and article pages (NewsArticle schema)
### Semantic HTML: <article>, <nav>, <main>, <aside>, <header>, <footer>
### next-sitemap config with all routes
### robots.txt: allow all crawlers
### Image: always use alt text, next/image with sizes prop
